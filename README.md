# 🧠 Project 4. 나는 착유한다, 고로 존재한다  
**스마트팜 착유량 예측 및 이상탐지 대시보드 구축**  
농가가 실시간으로 축산 데이터를 모니터링하고 이상 징후를 감지하며 착유량을 예측할 수 있는 데이터 기반 스마트 축산 시스템  

---

## 📌 프로젝트 요약  
**문제 상황:**  
스마트팜 기술은 빠르게 확산되고 있지만, 농가는 데이터 해석과 이상 징후 대응에 어려움을 겪음.  
전체 축산 농가의 26.4%가 스마트팜 도입 후 활용 미숙 및 장비 문제를 어려움으로 꼽음.  

**해결 목표:**  
농가가 직관적으로 데이터를 모니터링하고, 이상 상태를 조기에 탐지하며, 착유량을 예측할 수 있는 **스마트 축산 대시보드 구축**  

**핵심 모델 / 접근 방식:**  
- 논문 및 공문서를 기반으로 주요 생리 지표의 정상 범위 조사  
- **Isolation Forest**로 비정상 데이터를 자동 감지  
- **CatBoost Regressor**로 착유량 예측 및 성능 개선  
- Tableau + Streamlit 기반 **실시간 대시보드**로 시각화  

**역할:**  
정상 범위 조사, 이상탐지·예측모델링, Tableau 대시보드 설계 전 과정 주도 (기여도 약 70%)

---

## 🧰 기술 스택  
`Python` · `Pandas` · `NumPy` · `Scikit-learn` · `CatBoost` · `IsolationForest`  
`Tableau` · `Streamlit` · `Matplotlib` · `Seaborn` · `Joblib` · `Git` · `Jupyter Notebook`
